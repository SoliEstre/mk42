# Security

Please report security problems privately through GitHub's **Report a vulnerability** (Security tab → Advisories) on this repository. Do not open a public issue.

Include what you found, how to reproduce it, and the Mk42 version (Windows Settings → Apps → Mk42). You will get an answer within a few days.

In scope: the daemon (`mk42d`) and its local IPC, the hub window and its local server, the built-in extension, the self-updater and its update channel, the setup engine and installer, and the patches applied to Code - OSS. Vulnerabilities in Code - OSS itself, Electron, or the Claude Code / Codex extensions belong to their upstream projects.

Supported versions: the latest release only.
